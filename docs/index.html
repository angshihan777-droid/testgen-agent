运作流程

一个 6 节点的 LangGraph 自主循环：生成 → 运行 → 评估 → 修正，直到达标

1analyze · 静态分析
用 ast 解析源码，提取函数、分支与源码哈希
↓
2generate · 生成/修正测试
按源码与上一轮报错，用 LLM 写或修 pytest 测试
↓
3·4execute · 沙盒运行 + 变异
源码只读隔离，真实跑 pytest --cov，再做变异测试
↓
5evaluate · 门禁与归因
防篡改校验 + 覆盖率门禁 + 判断失败是测试错还是源码 bug
retry ↺ 回到生成 review ⏸ 人工确认 done ✓ 收敛
↑ retry / review 时循环回到上游，这是它作为 Agent 的自主闭环
↓
6report · 量化报告
覆盖率变化、变异杀伤、确认的 bug、门禁结果

核心能力

所有判定都建立在真实运行的结构化结果之上，而非模型的主观判断

🔁

自动生成与修正

生成测试后真实运行，失败时读取报错堆栈自动重写，无需人工介入。

🧬

测试有效性验证

用变异测试对源码做微小改动后重跑，判断测试是否真正覆盖了逻辑，而非只堆覆盖率数字。

🐛

源码 bug 识别

当测试在原始源码上失败、却能在某个变异体上通过时，判定为疑似源码 bug 并上报。

🔒

沙盒隔离防篡改

源码在沙盒中只读，运行前后做哈希校验，确保结果不被源码改动干扰。

✋

人工审核

仅在出现疑似源码 bug 时通过 interrupt 暂停，交由使用者确认，其余全自动完成。

🔌

可作为 MCP 工具

封装为 MCP 工具，可集成到 Codex、Claude 等 Agent 工作流中被调用。
